# Static Pages for MarinaDotNet Portfolio

This directory contains a static, lightweight version of my personal portfolio website.

It complements the main **React + Vite portfolio application** and provides an alternative way to explore the same professional information in a simpler, more traditional format.

## Purpose

The static version was created to ensure:
- Clear and distraction-free presentation of content
- Accessibility for users who prefer classic website layouts
- Availability without reliance on JavaScript frameworks
- A reliable fallback in case the React application is unavailable or unsuitable for a specific environment

While the main portfoio focuses on interactive UI and console-style navigation, this version prioritizes **readablility and simplicity**.

## Key Characteristic

- Plain HTML and CSS
- No client-side routing or farmework dependencies
- Fast loading and minimal resource usage
- Fully compatible with GitHub Pages
- Works independently of the React application

## Access

Once deployed, the static pages can be accessed directly:
https://marinadotnet.github.io/static

## Relationship to the Main Portfolio

This repository contains **two portfolio representations**:
- **React Portfolio (Primary)**
  An interactive React + Vite application with a Developer Console/Visual Studio-inspired interface, focused on UI experimentation and SPA architecture.
- **Static Portfolio (Alterantive)**:
  A simplified static website presenting the same core information with a traditional layout and straightforward navigation.

Both versions are maintained intentionally to offer **different viewing experiences** depending on user preferences or technical constraints.

## When This Version Is Recommended 

This static version may be preferable if:
- You prefer classic website layouts over interactive UIs
- You want quick access to content without animations
- You are viewing the portfolio in a resttricted or low-performance environment
- You want a clean, minimal reading experience
