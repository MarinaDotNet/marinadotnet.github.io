# MarinaDotNet Portfolio

Personal developer portfolio built with **React + Vite**, designed as an interactive **Developer PowerShell-style console UI**.

This project is part of my journey as a **Junior .NET/Frontend Developer**  and is actively evolving.

## 🚧 Project Status

**Work in progress.**
The portfolio is under active development. New features, refinements, and content are added incrementally to reflect my learning process and real-world architectural decisions.

## 🎯 Purpose

The main goals of this project are:
- Present my projects and technical background in a non-standard, memorable format
- Demonstrate clean React architecture and state management
- Showcase an interface concept inspired by a developer console (PowerShell)

## 🧩 Key Features

- Console-like UI with command-based navigation
- Optional console animation with configurable speed
- Dark/Light theme support
- Persistent user settings via `localStorage`
- React Router-based navigation
- Clear separation of UI, logic, and configuration

## 🛠 Tech Stack

**Frontend**
- React
- Vite

**Architecture Principles**
- Component responsibility separation
- Minimal side effects
- Predictable state handling
- Junior-friendly, interview-ready code
